Verificar relatório

Informe o código completo impresso no rodapé do relatório (ou leia o QR code). A verificação recalcula o código a partir dos dados oficiais publicados para a versão indicada.

Como funciona

O código de cada relatório é calculado (SHA-256) a partir da versão dos dados, do recorte, do ano de referência, da data e hora de geração e de toda a série do recorte. Se o código confere, os números do relatório são os publicados pela plataforma para aquele recorte e versão. Compare os valores abaixo com os do documento: qualquer alteração nos números impressos aparece como diferença. Versões anteriores dos dados continuam publicadas para que relatórios antigos possam ser verificados. A data e a hora de geração informam quando o relatório foi produzido, mas não são atestadas por terceiros.
